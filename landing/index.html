SkillLab benchmarks agent skills against a no-skill control, so your agency ships evidence — not adjectives.

Clone the workbench see it work ↓

Three moves to a verdict.

First, hand it a skill.

lab skill add github.com/your-org/commit-skill
skillcommit-helper
variantsv1 · v2-bad · v3-bp
immutableyes — edits mint new variants

Then run the benchmark.

lab experiment run bench-01
# control: no skill · treatment: v3-bp · model: any
job 8f2c — running simulated
armtreatment · commit-helper@v3-bp
taskwrite-commit-message
runs34 / 52

Control runs the same tasks with no skill.

Every delta is measured against an honest baseline — Δ vs control, not vs vibes

Every run pins the exact content hash.

Evidence is tied to sha256:845032… — edit one line and old runs stop counting

New version? The regression suite decides.

v3-bp vs v1 → clean · six categories, per-task metrics, artifact diffs

Mock runs stay labelled simulated.

A simulated badge on every mock artefact — it never counts as real evidence
